## ✨ 為什麼做 LinguaLoop？

學英語最怕「割裂」——背單字用一個 App、練聽力換一個網站、查文法翻筆記、練口說又無從下手，學完就忘、開不了口。

**LinguaLoop（林瓜魯普）** 把音、詞、法、聽、讀、寫、說七個環節連成一條真正的**學習閉環**：

> **打基礎 → 大量輸入 → 主動輸出** —— 讓每一個學過的單字、練過的句型，最終都能**聽得懂、說得出、讀得順、寫得對**。

| 5 項技能 | 12 個學習模組 | 5 萬+ 離線詞條 | 原始碼公開 |
| :---: | :---: | :---: | :---: |
| 聽 · 說 · 讀 · 寫 · 譯 | 環環相扣的學習閉環 | 內建字典秒級查字 | 個人免費 · 自行部署 |

## 🗺️ 一套系統，配齊學英語的全部環節（12 大模組）

| 階段 | 包含模組與核心體驗 |
| --- | --- |
| **1. 打基礎 · 發音與詞彙** | **音標學習**（48 個國際音標 + 42 個拼讀組合，點一下就能聽）· **音標練習**（內建 IPA 鍵盤實戰）· **單字學習**（音節拆分 + 字根構詞鍵盤跟打）· **字根字首**（同源字族圖譜串聯，學一個通一串） |
| **2. 鞏固與工具** | **生錯字本**（**「三連對」靶向清零機制**，拒絕虛假記憶）· **單字查詢**（5 萬+ 離線詞條秒查 + AI 分段補全）· **字庫管理**（內建基礎詞 / 四六級 / 考研 / 核心 4000 / IT 字庫，支援 CSV/TXT/JSON 自由匯入） |
| **3. 輸入 · 聽與讀** | **聽力廣場**（片語 / 情境對話 / 英語電台，變速播放 + 雙語字幕，一鍵跳轉翻譯精練）· **雙語閱讀**（**音標 / 原文 / 譯文三行對照**，點字即查即讀）· **基礎文法**（詞性、16 時態矩陣、句子成分推導視覺化圖解） |
| **4. 輸出 · 寫與說** | **單字默寫**（聽音盲打默寫，錯字自動歸集重考）· **句子翻譯**（核心詞熱身 → 整句盲打 → 逐字文法成分拆解）· **AI 口說陪練**（日常閒聊 / 出國旅行 / 職場 interview / 雅思口說真實情境角色扮演，即時糾音與文法回饋） |

## 🔥 讓人上癮的細節打磨

- 🎯 **「三連對」才算真的會**：拼錯或偷看提示自動進錯字本，必須**連續 3 次盲打全對**才清零，徹底告別「看著眼熟以為會了」。
- 🎹 **13 款真實採樣機械鍵盤軸體**：Cherry 青軸/茶軸、Topre 靜電容、羊駝軸、奶油軸、IBM 屈伸彈簧……真實按鍵聲 + 通關音效，讓背單字和默寫像玩機械鍵盤一樣紓壓上癮。
- 🎨 **7 套護眼主題一鍵換膚**：深色沉靜專注，淺色紙墨溫潤，全站 CSS 變數即時切換，長時間學習不累眼。
- 🗣️ **閉環的最後一環：AI 口說陪練**：隨時扮演咖啡店員、外商面試官、雅思考官陪你開口練，即時糾錯並把生字沉澱回你的專屬字庫。

## 📦 快速開始

### 環境需求

- **Node.js** `>= 20`
- **npm** `>= 10`

### 本機執行

```bash
# 1. 複製儲存庫
git clone https://github.com/easybuild-jack/lingualoop.git
cd lingualoop

# 2. 安裝相依套件
npm install

# 3. 啟動開發伺服器（無需任何後端或環境變數）
npm run dev
```

啟動後於瀏覽器開啟 `http://localhost:3000` 即可開始學習。

### 常用指令

```bash
npm run dev       # 啟動本機開發伺服器
npm run build     # 建置正式版本
npm run start     # 啟動正式環境服務
npm run lint      # ESLint 程式碼規範檢查
```

### 選用功能設定

| 功能 | 設定方式 |
| --- | --- |
| **AI 查字 / AI 助教 / 口說陪練** | 啟動後進入右上角「偏好設定 → AI 模型 / 語音設定」填入自己的 API Key（僅存本機瀏覽器） |
| **跨裝置與團隊共享（Supabase）** | 在自己的 Supabase SQL Editor 中執行 [`supabase/schema.sql`](./supabase/schema.sql)，再於「偏好設定 → 資料同步」填入 Project URL 與 Anon Key |
| **自部署規範網域（SEO）** | 建置前設定環境變數 `NEXT_PUBLIC_SITE_URL=https://your-domain.com`（選填） |
