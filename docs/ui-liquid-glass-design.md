## 一、视觉底座规范（毛玻璃质感）

- **背景策略（无光晕、护眼耐看）**：
  - **视频同款纯裸粉**：纯色 `#DFC6BD`（备选更浅：`#EDD9D2`）
  - **教室黑板**：哑光深墨绿 `#1A2922` + 极细粉笔灰肌理
  - **纯淡雾青 / 纯淡米纸**：`#EAF1EF` / `#F3EFE6`
- **双层嵌套玻璃卡片**：
  - 主容器与子模块叠加磨砂层次：`backdrop-filter: blur(28px) saturate(140%)`
  - 浅色底卡片采用半透明白（`44%–64%` 透明度），深色底采用低透明度白膜（`3%–9%`）
  - `1px` 半透明玻璃描边 + 顶部细微内高光（`inset 0 1.5px 0`）+ 大圆角（`24px–26px`）+ 大面积柔和扩散阴影
- **视觉锚点与点缀色**：
  - 浅色系下搭配一块 **深炭黑锚点卡片**（`#1B1B19`，如「构词记忆」模块）稳住构图重心
  - 配合 **赤陶橙**（`#C26B46`）或当前皮肤主色作为进度条、词根、高亮词点缀

## 二、6 大交互效果与 LinguaLoop 落点映射

| 编号 | 交互名称 | 视觉与动效特征 | 技术方案 | LinguaLoop 建议落点 |
| :--- | :--- | :--- | :--- | :--- |
| **01** | **液态高亮块 (Liquid Pill)** | 菜单切换时，半透明玻璃胶囊带运动拉伸（果冻感）与弹簧回弹滑到目标项 | Framer Motion `layoutId` / Web Animations API `scaleY` 拉伸 | `AppSidebar` 左侧导航激活态、`WordDisplay` 例句/短语 Tab |
| **02** | **光跟着鼠标走 (Light Follow)** | 鼠标移过卡片时，内部柔和聚光 + 最近 `1px` 边框局部点亮 + 极轻微 3D 倾角 | `pointermove` 更新 `--mx/--my` + `mask-composite` 边框发光 + `perspective` | 例句/短语卡、构词卡、词库书卡（主跟打区倾角压到 `≤0.6°` 防晕） |
| **03** | **模块就地放大 (Expand in Place)** | 点击模块右上角展开，原位平滑放大填满舞台，其余模块收为底部玻璃缩略图条 | FLIP / Framer Motion 共享布局过渡 | 学习页的单词跟打区、例句/短语精读区、构词解析区 |
| **04** | **水滴分裂筛选 (Liquid Split)** | 单颗胶囊点击后通过粘连融合动效分裂出多个选项水滴，选完后融合收回 | SVG `<filter>` (`feGaussianBlur` + `feColorMatrix` Gooey) | `HeaderToolbar` 的「美音/英音」切换与「循环 1/2/3/5 次」筛选 |
| **05** | **命令面板 (Command Palette)** | `Ctrl+K` / `⌘K` 唤起居中毛玻璃弹层，底层背景柔焦暗化，实时搜索高亮与键盘选择 | React Modal + `backdrop-filter` + 全局快捷键监听 | 全局快速查词、切单元/词书、切模式、切皮肤与菜单形态 |
| **06** | **玻璃停靠栏 (Glass Dock)** | 底部居中悬浮玻璃胶囊，鼠标滑过图标产生 macOS 式距离余弦波浪放大 + 悬浮名称 | 指针 X 轴距离余弦衰减计算 `scale` + `translateY` | 作为 `AppSidebar` 的可选沉浸模式（给背词腾出更大横向视野） |
