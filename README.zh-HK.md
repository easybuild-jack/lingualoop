## ✨ 為什麼做 LinguaLoop？

學英語最怕「割裂」——背生字用一個 App、練聽力換一個網站、查語法翻筆記、練口語又無從入手，學完即忘、開不了口。

**LinguaLoop（林瓜魯普）** 將音、詞、法、聽、讀、寫、說七個環節連成一條真正的**學習閉環**：

> **打基礎 → 大量輸入 → 主動輸出** —— 讓每一個學過的單詞、練過的句型，最終都能**聽得懂、說得出、讀得順、寫得對**。

| 5 項技能 | 12 個學習模塊 | 5 萬+ 離線詞條 | 100% 代碼開源 |
| :---: | :---: | :---: | :---: |
| 聽 · 說 · 讀 · 寫 · 譯 | 環環相扣的學習閉環 | 內置詞典秒級查詞 | 私人訂製 · 自由部署 |

## 🗺️ 一套系統，配齊學英語的全部環節（12 大模塊）

| 階段 | 包含模塊與核心體驗 |
| --- | --- |
| **1. 打基礎 · 發音與詞彙** | **音標學習**（48 個國際音標 + 42 個拼讀組合，點一下就能聽）· **音標練習**（內置 IPA 鍵盤實戰）· **單詞學習**（音節拆分 + 詞根構詞鍵盤跟打）· **詞根詞綴**（同源詞族圖譜串聯，學一個通一串） |
| **2. 鞏固與工具** | **生錯詞本**（**「三連對」靶向清零機制**，拒絕虛假記憶）· **單詞查詢**（5 萬+ 離線詞條秒查 + AI 分段補全）· **詞庫管理**（內置基礎詞 / 四六級 / 考研 / 核心 4000 / IT 詞庫，支援 CSV/TXT/JSON 自由匯入） |
| **3. 輸入 · 聽與讀** | **聽力廣場**（短語 / 場景對話 / 英語電台，變速播放 + 雙語字幕，一鍵跳轉翻譯精練）· **雙語閱讀**（**音標 / 原文 / 譯文三行對照**，點詞即查即讀）· **基礎語法**（詞性、16 時態矩陣、句子成分推導可視化圖解） |
| **4. 輸出 · 寫與說** | **單詞默寫**（聽音盲打默寫，錯詞自動歸集重考）· **句子翻譯**（核心詞熱身 → 整句盲打 → 逐詞語法成分拆解）· **AI 口語陪練**（日常閒聊 / 出國旅行 / 職場 interview / 雅思口語真實場景角色扮演，即時糾音與語法反饋） |

## 🔥 令人上癮的細節打磨

- 🎯 **「三連對」才算真的會**：拼錯或偷看提示自動進錯詞本，必須**連續 3 次盲打全對**才清零，徹底告別「睇落眼熟以為識」。
- 🎹 **13 款真實採樣機械鍵盤軸體**：Cherry 青軸/茶軸、Topre 靜電容、羊駝軸、奶油軸、IBM 屈伸彈簧……真實按鍵聲 + 通關音效，讓背單詞與默寫像玩機械鍵盤一樣解壓上癮。
- 🎨 **7 套護眼主題一鍵換膚**：深色沉靜專注，淺色紙墨溫潤，全站 CSS 變量即時切換，長時間學習不累眼。
- 🗣️ **閉環的最後一環：AI 口語陪練**：隨時扮演咖啡店員、外企面試官、雅思考官陪你開口練，即時糾錯並將生詞沉澱回你的專屬詞庫。

## 📦 快速開始

### 環境要求

- **Node.js** `>= 20`
- **npm** `>= 10`

### 本地運行

```bash
# 1. 複製倉庫
git clone https://github.com/easybuild-jack/lingualoop.git
cd lingualoop

# 2. 安裝依賴
npm install

# 3. 啟動開發服務器（無需任何後端或環境變量）
npm run dev
```

啟動後在瀏覽器瀏覽 `http://localhost:3000` 即可開始學習。

### 常用指令

```bash
npm run dev       # 啟動本地開發服務器
npm run build     # 構建生產版本
npm run start     # 啟動生產服務
npm run lint      # ESLint 代碼規範檢查
```

### 可選功能配置

| 功能 | 配置方式 |
| --- | --- |
| **AI 查詞 / AI 助教 / 口語陪練** | 啟動後進入右上角「偏好設定 → AI 模型 / 語音設定」填入自己的 API Key（僅存本機瀏覽器） |
| **跨裝置與團隊共享（Supabase）** | 在自己的 Supabase SQL Editor 中執行 [`supabase/schema.sql`](./supabase/schema.sql)，再於「偏好設定 → 數據同步」填入 Project URL 與 Anon Key |
| **自部署規範域名（SEO）** | 構建前設定環境變量 `NEXT_PUBLIC_SITE_URL=https://your-domain.com`（可選） |
